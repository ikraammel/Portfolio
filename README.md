# Developer Portfolio

Personal developer portfolio built with React and Vite.

## Tech stack

- JavaScript
- React
- Vite

## Run locally

```bash
git clone https://github.com/ikraammel/Portfolio.git
cd Portfolio
npm install
npm run dev
```
